# програма Configuration of seismic data
## Требования для запуска
### - Python 3.13.3
## как запустить
### написать код каторый будет использовать класс Configuration_of_seismic_data и прописать функцию .processing('путь до файла') 
### "путь до файла" может быть абсолютным или отностиельным и должен иметь название файла с формата .sgy
